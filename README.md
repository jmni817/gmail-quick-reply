# Gmail 빠른 답변 버튼 (Chrome Extension, Manifest V3)

Gmail 답장 · 전달 · 새 메일 작성 창의 본문 바로 위에 버튼 바를 띄우고,
클릭 한 번으로 미리 저장한 답변 초안을 본문에 입력합니다.

## 폴더 구조

```
gmail-quick-reply/
├─ manifest.json   # 확장 프로그램 설정 (MV3)
├─ icons/          # 확장 아이콘 (16/32/48/128px)
├─ defaults.js     # 최초 설치 시 넣는 예시 버튼 1개 + 저장 키 (공용)
├─ background.js   # 최초 설치 시 기본값 저장, ⚙ 버튼 → 설정 탭 열기
├─ content.js      # Gmail 화면에 버튼 바 주입 + 본문 입력 로직
├─ styles.css      # 버튼 바 스타일
├─ popup.html      # 버튼 관리 화면 (툴바 팝업 / 옵션 페이지 공용)
└─ popup.js        # 버튼 추가·수정·삭제·순서 변경, 자동 저장
```

## 설치 방법

1. Chrome 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → `gmail-quick-reply` 폴더 선택
4. 이미 열려 있던 Gmail 탭은 **새로고침(F5)** (콘텐츠 스크립트는 새로 연 페이지에만 들어갑니다)
5. 답장/전달/편지쓰기를 누르면 본문 위에 버튼 바가 나타납니다

코드를 고친 뒤에는 `chrome://extensions`에서 이 확장의 🔄(새로고침) 버튼을 누르고 Gmail 탭도 새로고침하세요.

## 사용법

- **버튼 클릭**: 해당 초안이 본문에 입력됩니다. Ctrl+Z로 되돌릴 수 있습니다.
- **버튼 관리**: 툴바의 확장 아이콘 클릭(팝업) 또는 버튼 바 오른쪽 끝 ⚙ 클릭(새 탭)
  - 목록에는 버튼 이름만 보이고, **편집**을 누른 버튼만 이름·본문 편집 칸이 펼쳐집니다 (한 번에 하나).
  - 이름에 마우스를 올리면 본문 미리보기가 보입니다.
  - 고친 내용은 자동 저장되고, 열려 있는 Gmail 버튼 바에도 바로 반영됩니다.
  - **기본값 복원**을 누르면 예시 버튼 1개만 남은 처음 상태로 돌아갑니다.
- **삽입 방식** (관리 화면 상단에서 선택)
  | 방식 | 동작 |
  |---|---|
  | 커서 위치 (기본) | 마지막으로 본문에 있던 커서 위치에 삽입. 선택한 글자가 있으면 그 부분을 대체. 커서 기록이 없으면 본문 끝 |
  | 본문 끝 | 작성한 내용 끝에 빈 줄 하나 띄우고 이어붙임 |
  | 덮어쓰기 | 작성한 내용을 지우고 초안으로 교체 |

  어떤 방식이든 **서명과 인용된 이전 메일은 건드리지 않고** 그 앞에 넣습니다. 본문이 비어 있으면 방식과 상관없이 맨 위에 넣습니다.

## 구현 메모

- **에디터 탐색**: 난독화된 클래스명 대신 `g_editable="true"` 속성, 또는 `role="textbox"` + `aria-label`에 "본문"/"body"가 들어간 요소로 찾습니다. 한국어 Gmail의 "메시지 본문", 영어 "Message Body" 모두 해당합니다.
- **겹침 방지 배치**: 버튼 바가 본문보다 화면상 완전히 위에 있는지 좌표로 확인하고, 겹치거나 옆에 붙으면 한 단계씩 바깥 요소 앞으로 옮깁니다. `ResizeObserver`로 글을 입력해 본문 크기가 바뀔 때마다 다시 확인합니다.
- **중복 방지 / 재오픈 대응**: `MutationObserver`가 DOM 변화를 150ms 단위로 모아 스캔하고, 에디터 ↔ 버튼 바를 `WeakMap`으로 연결해 이미 붙어 있으면 건너뜁니다. 에디터가 사라지면 바도 함께 정리됩니다.
- **입력 방식**: Gmail은 Trusted Types 정책 때문에 `innerHTML`/`insertHTML` 같은 HTML 문자열 삽입을 막습니다. 그래서 줄 내용은 `execCommand('insertText')`, 줄바꿈은 `execCommand('insertParagraph')`(Gmail과 같은 `<div>` 문단)로 "타이핑하듯" 넣고, 실패하면 텍스트 노드와 `<br>`을 직접 만들어 넣습니다. 끝나면 `input` / `change` 이벤트를 발생시켜 초안 자동 저장과 맞춥니다.
- **클릭 처리 / 포커스 유지**: Gmail이 작성 창 안의 마우스 이벤트를 가로채는 경우가 있어, 클릭은 `window` 캡처 단계에서 가장 먼저 받아 처리합니다. `mousedown` 기본 동작을 막아 클릭해도 커서가 본문에서 빠지지 않고, 버튼은 모두 `type="button"`이라 폼 제출이 일어나지 않습니다.
- **문제 확인**: 개발자 도구(F12) 콘솔에 `[Gmail 빠른 답변]` 로그가 남습니다 (로드, 버튼 바 부착, 입력 성공/오류).
- **저장소**: `chrome.storage.local`을 씁니다. `sync`는 항목 하나당 8KB 제한이 있어 긴 템플릿 여러 개를 담기에 빠듯하기 때문입니다. 기기 간 동기화가 필요하면 `popup.js`/`content.js`/`background.js`의 `chrome.storage.local`을 `chrome.storage.sync`로 바꾸면 됩니다 (템플릿 전체가 8KB를 넘지 않는 범위에서).
